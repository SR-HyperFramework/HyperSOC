# MITRE T1053 — Scheduled Task/Job

## Metadata

- source: MITRE
- technique: T1053
- category: persistence

Scheduled tasks and jobs can provide recurring execution and persistence. Registry,
PowerShell, and task-scheduler evidence in one bounded timeline supports further
investigation.

## Investigation

Review task name, creator, execution path, account, trigger, and parent process
using approved endpoint tooling. Do not execute untrusted commands from evidence.
