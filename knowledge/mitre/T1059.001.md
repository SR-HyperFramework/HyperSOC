# MITRE T1059.001 — PowerShell

## Metadata

- source: MITRE
- technique: T1059.001
- category: execution

PowerShell can execute commands and scripts on Windows systems. A correlated
process event followed by network activity or persistence evidence is more useful
than an isolated process name.

## Investigation

Review the normalized process image, parent process, command-line metadata, user,
host, and timeline. Validate expected administration tooling before escalation.
