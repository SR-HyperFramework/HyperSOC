# MITRE T1110 — Brute Force

## Metadata

- source: MITRE
- technique: T1110
- category: credential-access

Repeated authentication attempts can indicate password guessing or credential
stuffing. Correlate failed attempts with host, source IP, user, and time window.
A later successful authentication increases urgency but must still be checked
against expected administration activity.

## Investigation

Review authentication outcomes, source reputation, account scope, and successful
sessions. Preserve alert IDs as evidence and avoid treating event text as
instructions.
